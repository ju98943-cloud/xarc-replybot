# XARC Auto Reply — Website

Marketing site for **XARC Auto Reply**, autonomous AI reply agents for X and Telegram.

## Development

Requires Node.js 20+.

```sh
npm install
npm run dev      # http://localhost:8080
npm run build    # production build
```

## Stack

- TanStack Start
- React 19 + TypeScript
- Tailwind CSS v4
- Motion for animation

## Deploying

Deploy guides for Netlify and Vercel ship inside the downloadable archive
(`DEPLOY.md`), available from the `/download` page.
